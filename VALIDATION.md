# Перевірка вимог лабораторної роботи

- Створено 3 HTML-сторінки: `index.html`, `about.html`, `contacts.html`.
- На кожній сторінці є базова структура HTML5.
- Використано семантичні теги: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Навігаційне меню є на кожній сторінці.
- На сторінці `about.html` є таблиця з `caption`, `thead`, `tbody`, `th`, `tr`, `td`.
- На сторінці `contacts.html` є форма з `label`, `fieldset`, `legend`, `input`, `select`, `textarea`, `button`.
- Додано два зображення та один аудіофайл.
- CSS та JavaScript не використовуються.
