# Портфоліо — Лабораторна робота 1

Проєкт створений для предмету **Front end (25-26)**.

## Опис

Це персональний портфоліо-сайт майбутнього фронтенд-розробника. Сайт складається з трьох HTML-сторінок:

- `index.html` — головна сторінка;
- `about.html` — інформація про студента, навички, таблиця, список описів і мультимедіа;
- `contacts.html` — контактна інформація та форма зворотного зв'язку.

## Використані технології

- HTML5;
- Git;
- GitHub.

CSS та JavaScript не використовуються відповідно до умов лабораторної роботи.

## Структура проєкту

```text
portfolio/
├── .gitignore

├── about.html
├── contacts.html
├── images/

```

## Як запустити

Відкрити файл `index.html` у браузері.
