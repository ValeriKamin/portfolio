# Персональне портфоліо

Навчальний сайт-портфоліо, створений у межах дисципліни **Front end (25-26)**.

Проєкт розробляється поступово в межах лабораторних робіт:

- **Лабораторна робота 1** — створення HTML-структури сайту.
- **Лабораторна робота 2** — стилізація сторінок за допомогою CSS.
- **Лабораторна робота 3** — адаптивна верстка, Mobile First, Flexbox, CSS Grid, CSS-змінні, переходи та анімації.

## Опис проєкту

Сайт представляє персональне портфоліо майбутнього фронтенд-розробника.  
Він складається з декількох HTML-сторінок, має спільну навігацію, оформлення та адаптивну структуру для різних пристроїв.

## Сторінки сайту

- `index.html` — головна сторінка з коротким представленням.
- `about.html` — сторінка з інформацією про освіту, навички та інтереси.
- `contacts.html` — сторінка з контактною інформацією та формою зворотного зв'язку.

## Використані технології

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS-змінні
- Media queries
- Git
- GitHub

## Що реалізовано

### HTML

- семантична структура сторінок;
- теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- таблиця навичок;
- форма зворотного зв'язку;
- зображення та аудіо;
- коректна структура HTML-документа.

### CSS

- зовнішній файл стилів `styles.css`;
- відсутність inline-стилів;
- глобальне правило `box-sizing: border-box`;
- стилізація навігації, таблиці, форми, карток і футера;
- псевдокласи `:hover`, `:active`, `:focus-visible`, `:nth-child`;
- псевдоелементи `::before` та `::after`;
- використання `position`, `z-index`, `overflow`;
- підключення Google Fonts.

### Адаптивність

- підхід **Mobile First**;
- підтримка екранів від 320px;
- адаптація під мобільні телефони, планшети, ноутбуки та великі монітори;
- використання `@media`;
- адаптивні розміри через `clamp()`, `min()` та відносні одиниці;
- CSS Grid для побудови сіток;
- Flexbox для меню, кнопок, футера та списків.

### Додаткові можливості

- CSS-змінні для керування кольорами, відступами, радіусами та тінями;
- автоматична темна тема через `prefers-color-scheme`;
- плавні переходи через `transition`;
- анімації через `@keyframes`;
- підтримка `prefers-reduced-motion` для користувачів, які вимикають анімації.
